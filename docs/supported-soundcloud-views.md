# 👀 Supported SoundCloud views

Likes to Go can export from your SoundCloud likes page when it's shown in **Badges** or **List** view. Use SoundCloud's view switcher on your likes page to choose either layout before you start.

If the export fails because the page layout isn't recognized, switch to the other supported view and try again. Other likes page layouts aren't supported in this release.

The two views expose different track details. See [What's in the export file](export-format.md) for field availability by view.
